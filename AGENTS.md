# Repository guidance

Pre-existing coursework artifacts are immutable: do not edit, rename, move, delete, normalize, or overwrite source, notebooks, reports, assignment PDFs, data, figures, or results. New documentation may be added at the root, in docs/, and as new project documentation. Preserve existing documentation unless editing is explicitly authorized.

Do not execute training, notebook cells, downloads, or report generators without explicit approval and an isolated working copy. Verify claims against code, reports, and saved outputs. Distinguish requested tasks, implemented methods, and recorded measurements. Hash existing files before and after documentation work.

Read PUBLICATION_REVIEW.md before publication. Never publish credentials, personal identifiers, private data, or restricted course materials. Do not commit, push, or change hosting settings without user authorization.
